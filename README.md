# 🤖 Quantum Bet Bot v12 PRO — Ваш умный              помощник для ставок

## 📖 Описание
Мощный Telegram бот для поиска валуйных ставок на футбол с использованием передовых технологий машинного обучения и анализа данных.

### 🔥 Возможности:
- 📊 **Poisson распределение** — точнее чем нормальное распределение
- 🧠 **Машинное обучение** — ML + Нейросеть для точных прогнозов
- 🔍 **Поиск аномалий** — находит завышенные коэффициенты
- 🤖 **Авто-ставки** — автоматически ставит при EV > 50%
- 📈 **Веб-приложение** — графики, статистика, симулятор
- 📱 **Работает на телефоне** — через Pydroid / QPython
- 🎯 **Прогноз точного счета** — топ-5 наиболее вероятных счетов
- 📐 **Прогноз угловых** — тоталы и вероятности
- 🟨 **Прогноз желтых карточек** — на основе статистики

## 🚀 Быстрый старт

### 💻 На компьютере

```bash
# Клонируем репозиторий
git clone https://github.com/seva2288-prog/Quantumnet_bot-PRO.git
cd Quantumnet_bot-PRO

# Устанавливаем зависимости
pip install -r requirements.txt

# Создаём .env файл
cp .env.example .env
# Отредактируйте .env (вставьте свои токены)

# Запускаем бота
python app/bot.py
